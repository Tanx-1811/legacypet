# Code of Conduct

LegacyPet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and welcome newcomers. This project is about caring for things, people included.
Harassment, insults and personal attacks are not tolerated.

To report a problem, open a private [security advisory](https://github.com/Tanx-1811/legacypet/security/advisories/new)
or contact the maintainer listed on the repository profile. Reports are handled confidentially.
